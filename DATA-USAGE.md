# Data usage disclosure

Experience Edge Console runs inside SitecoreAI and gives administrators a UI
for the Experience Edge Admin API (webhooks, cache, environment settings).
It stores the Edge administration Client ID and the sealed Client Secret in
a Settings item in your own SitecoreAI environment, and calls Sitecore Cloud
and the Admin API through its own server routes. It has no database and uses
no analytics. Hosting: Vercel; serverless functions run in the United States
(Vercel default region `iad1`, Washington, D.C.) unless the deployment sets
another region.

See also the [Privacy policy](PRIVACY.md) and [Security policy](SECURITY.md).
